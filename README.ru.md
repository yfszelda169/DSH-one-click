# Установщик DeepSeek Harness для Windows в один клик

[中文](README.zh.md) | [English](README.en.md) | [Français](README.fr.md) | [Español](README.es.md) | Русский | [العربية](README.ar.md)

Дважды щёлкните **install-deepseek-harness.cmd**, чтобы запустить установку. Это **автономный CMD-установщик в одном файле**, отдельный .ps1 не требуется. CMD извлекает встроенную логику во временный каталог Windows, запускает её встроенным PowerShell и затем удаляет временный файл. Установщик автоматически определяет язык системы Windows: китайский, английский, французский, испанский, русский или арабский. Язык можно принудительно задать переменной **DSH_INSTALLER_LANG**, например:

    set DSH_INSTALLER_LANG=ru
    install-deepseek-harness.cmd

## Быстрый старт

1. Дважды щёлкните **install-deepseek-harness.cmd**.
2. Дождитесь установки Node.js, Git и DeepSeek Harness.
3. Установщик один раз кратко запустит DeepSeek Harness для инициализации профиля Desktop и затем автоматически закроет его.
4. Выберите плагины по номерам, затем навыки. Примеры: 1 3 5 или 1,3,5; all выбирает всё; 0 — ничего.
5. Каждый плагин или навык загружается с GitHub. При тайм-ауте или ошибке установка завершается ошибкой; китайские зеркала для этого языка отключены.
6. DeepSeek Harness автоматически запустится после завершения.
7. Введите ключ API DeepSeek в DeepSeek Harness в разделе **Settings → Models**.

Проверка без установки:

    install-deepseek-harness.cmd -CheckOnly -NoLaunch

## Параметры

| Параметр | Описание |
|---|---|
| -CheckOnly | Только проверка среды и сети; ничего не устанавливает |
| -SkipPlugins | Пропустить выбор и установку плагинов/навыков |
| -NoLaunch | Не запускать DeepSeek Harness после установки |
| -Force | Принудительно переустановить настольное приложение |

## Что устанавливается

| Компонент | Источник / поведение |
|---|---|
| Официальное приложение DeepSeek Harness для Windows | https://download.deepseek.com/desktop/dsh-latest-windows-x64.exe |
| Node.js 24+ | Требуется >=24.9.0; сначала WinGet LTS, затем официальный ZIP. WinGet может вызвать UAC |
| Git for Windows | Сначала WinGet; ошибка не блокирует основной процесс. WinGet может вызвать UAC |
| WinGet | Используется при наличии; иначе Node.js ставится из официального ZIP |

Node.js нужен для find-skills и экосистемы DSH CLI. Python не требуется для базовой установки; необязательные плагины также не требуют системного Python.

## Пути по умолчанию

| Содержимое | Путь |
|---|---|
| DeepSeek Harness | %LOCALAPPDATA%\Programs\DeepSeek Harness |
| DSH_HOME | %USERPROFILE%\.dsh |
| Навыки | %USERPROFILE%\.dsh\skills |
| Журнал установщика | %LOCALAPPDATA%\DeepSeekHarnessInstaller |

Если задан DSH_HOME, установщик использует его.

## Только GitHub для этого языка

Китайские зеркала включаются только когда язык интерфейса установщика — китайский. Этот русский интерфейс использует только GitHub и никогда не переключается на npmmirror или jsDelivr.

Плагины используют закреплённые коммиты GitHub. Навыки используют GitHub Raw. Все Git-источники закреплены на коммитах и не используют плавающую ветку main.

## Настройка ключа API

Установщик не запрашивает, не проверяет и не сохраняет ключ API DeepSeek. После установки запустите DeepSeek Harness и введите ключ в **Settings → Models**. Ключ управляется собственным механизмом настроек и учётных данных DSH.

## Права администратора и UAC

- Настольное приложение DSH, плагины, навыки, пользовательский PATH и файлы в %USERPROFILE%\.dsh не требуют прав администратора.
- Node.js и Git сначала устанавливаются через WinGet с параметром --scope user. Если пакет WinGet не поддерживает пользовательскую установку, установщик может перейти к системной установке, и Windows покажет UAC.
- -CheckOnly только проверяет среду и сеть. Он ничего не устанавливает и не вызывает UAC.
- Для установки строго без UAC заранее установите Node.js >=24.9.0 и Git или адаптируйте установщик для полностью портативных версий Node.js и Git.
- Запускайте установщик от обычного пользователя. Скрипт предупреждает при запуске от администратора, поскольку повышенные права обычно не нужны.

## Проверка и безопасность

- Официальный установщик DSH проверяет подпись Authenticode и останавливается при ошибке.
- Выводится SHA256 установщика.
- Портативный ZIP Node.js проверяется по официальному SHASUMS256.txt.
- Плагины и навыки в этом языке используют только закреплённые источники GitHub. Резервные китайские зеркала включаются только для китайского интерфейса.
- Сторонние плагины выполняются в процессе DSH с правами вашего пользователя. Проверяйте каждый репозиторий перед установкой.

## Примечания

- Требуется 64-битная Windows 10/11, не менее 2 ГБ свободного места и подключение к Интернету.
- Установщик не обрабатывает ключ API. Настройте его в **Settings → Models** после первого запуска.
- Официальное приложение DSH устанавливается для текущего пользователя и обычно не требует прав администратора.
- При инициализации профиля Desktop приложение может ненадолго появиться; установщик закроет его автоматически.
- При ошибке плагина запустите установщик снова и выберите его повторно.
- DeepSeek Harness находится в Developer Preview; интерфейсы плагинов могут меняться. Версии закреплены в установщике.
- Перед удалением DeepSeek Harness удалите команду dsh, зарегистрированную приложением. Установщик только добавляет встроенный каталог CLI в пользовательский PATH.
