# DSH-one-click

**DeepSeek Harness Windows one-click installer.**

[中文](README.zh.md) | [English](README.en.md) | [Français](README.fr.md) | [Español](README.es.md) | [Русский](README.ru.md) | [العربية](README.ar.md)

This repository contains a single-file Windows CMD installer for DeepSeek Harness. It checks the environment, installs dependencies, installs the official Windows desktop app, lets you multi-select plugins and skills, and falls back to China mirrors when GitHub times out. The installer follows the Windows system language automatically and supports Chinese, English, French, Spanish, Russian, and Arabic. You can override the language with `DSH_INSTALLER_LANG` (for example, `set DSH_INSTALLER_LANG=fr`).
